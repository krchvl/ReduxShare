ReduxShare — dev playground

Страница живёт только в npm run dev и не попадает в сборку расширения. Moodle-фрагменты подгружены из тестовых фикстур, ответы и голоса замоканы в памяти.

Наведи курсор на контрол ответа — появится R-виджет: вкладки «Внутренние / Внешние / ИИ», «Точный ответ», «Статистика» с кнопками 👍/👎. Горячая клавиша — R. Клик по варианту применяет его к реальным контролам фикстуры.
